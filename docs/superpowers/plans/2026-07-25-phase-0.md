# Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a runnable Phase 0 pipeline — resume → `canonical_facts` → Greenhouse + Adzuna discovery → dedupe → pgvector prefilter → LLM scoring → tailoring behind a whitelist gate → WeasyPrint PDF → Next.js review queue.

**Architecture:** Every pipeline stage is a plain Python function with no framework in its signature. Celery tasks and CLI commands are thin wrappers. `packages/shared` has zero I/O and holds the schemas plus the whitelist gate, so the gate is built and tested before the tailoring engine exists.

**Tech Stack:** Python 3.14, FastAPI, SQLAlchemy 2 + Alembic, Postgres 17 + pgvector 0.8.5 (Homebrew), Anthropic SDK (Claude Sonnet 5), Voyage `voyage-3`, WeasyPrint, Jinja2, Typer, Next.js + Tailwind.

## Global Constraints

- **No sampling parameters.** `temperature` / `top_p` / `top_k` are rejected with a 400 on Claude Sonnet 5. Structure comes from `output_config.format` via `client.messages.parse()` with Pydantic models.
- **Adaptive thinking is on by default** on Sonnet 5 and `max_tokens` caps thinking + output together. Budget `max_tokens` with headroom (8000 scoring, 16000 tailoring).
- Model IDs: `claude-sonnet-5` (tailoring + scoring), `voyage-3` (embeddings, 1024-dim). No date suffixes.
- `packages/shared` imports nothing from `services/`.
- No secrets in code, tests, or fixtures. `.env` and `profile/` are gitignored.
- No network in tests. LLM and embedding clients sit behind Protocols with fakes.
- `JOBPILOT_FIXTURE_MODE=1` wires the fakes into the real pipeline so `run-pipeline` completes with zero API keys.

### Task 1: Scaffold + config

**Files:** Create `pyproject.toml`, `.env.example`, `packages/shared/jobpilot_shared/__init__.py`, `services/api/jobpilot_api/__init__.py`, `services/worker/jobpilot_worker/__init__.py`, `jobpilot_shared/settings.py`, `tests/test_settings.py`

**Produces:** `Settings` (pydantic-settings) with `database_url`, `anthropic_api_key`, `voyage_api_key`, `adzuna_app_id`, `adzuna_app_key`, `fixture_mode: bool`, `match_score_threshold: int = 70`, `max_tailored_per_day: int = 12`, `embed_top_k: int = 40`, `tailoring_model: str = "claude-sonnet-5"`, `embedding_model: str = "voyage-3"`.

Steps: write `test_settings.py` asserting defaults and `JOBPILOT_FIXTURE_MODE=1` → `fixture_mode is True` → run (fails) → implement → run (passes) → commit.

### Task 2: canonical_facts + tailoring IO schemas

**Files:** Create `jobpilot_shared/canonical_facts.py`, `jobpilot_shared/tailoring_io.py`, `tests/shared/test_canonical_facts.py`

**Produces:** `CanonicalFacts`, `Employment`, `Education`, `Identity`, `Links`; `TailoringOutput`, `TailoredBullet`. Frozen pydantic models matching PRD §4.1 and §4.4.

### Task 3: The whitelist gate ⚠️ priority task

**Files:** Create `jobpilot_shared/normalize.py`, `jobpilot_shared/lexicon.py`, `jobpilot_shared/whitelist.py`, `tests/shared/test_whitelist.py`

**Produces:** `check(facts, output) -> GateResult`; `Ok`, `Rejected`, `Violation(rule, severity, detail, evidence)`.

Four rules per spec §5: `unknown_skill` (reject), `yoe_inflation` (reject), `unknown_employer` (reject), `unlisted_token` (flag). Table-driven adversarial suite: casing, unicode lookalikes (`Kubernetes` with Cyrillic `е`), punctuation variants (`Node.js` ≡ `NodeJS` ≡ `node js`), YOE inflation, unknown employers, empty skills list.

**Lands before the tailoring engine.** No I/O, no DB, no LLM client.

### Task 4: Data model + migrations

**Files:** Create `jobpilot_shared/db/models.py`, `alembic.ini`, `migrations/versions/0001_initial.py`, `tests/test_models.py`

Schema per spec §6, including the partial unique indexes that enforce the dedupe rule.

### Task 5: Resume ingestion CLI

### Task 6: Greenhouse discovery + upsert

### Task 7: Aggregator + resolve + certainty dedupe

**Files:** Create `jobpilot_shared/scoring_io.py`, `jobpilot_worker/stages/score.py`, `tests/worker/test_score.py`

`client.messages.parse(model=..., max_tokens=8000, output_format=ScoreVerdict, ...)`. No `temperature`.

### Task 10: Tailoring engine + gate integration + retry

**Files:** Create `jobpilot_worker/prompts/tailor.py`, `jobpilot_worker/stages/tailor.py`, `tests/worker/test_tailor.py`

Max 3 attempts; each retry re-prompts with prior violations as explicit constraints. After 3 → `whitelist_passed=false`, application → `needs_human`. Test: fake client returns a hallucinated skill → gate rejects → retry → passes.

`render.py` asserts `whitelist_passed` before generating. Round-trip: generate → extract with `pdfplumber` → assert canonical name/employers/dates verbatim, no non-whitelisted skill anywhere.
